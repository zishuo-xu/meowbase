# M5 设计文档:Web UI(喵窝聊天界面)

- 日期:2026-08-16
- 状态:已批准(用户在会话中确认设计:猫耳气泡 + 每猫色板 + 暖纸色底)
- 依赖:M1-M4 API(threads/messages/profiles/evidence/skills/approvals + WebSocket 流式)
- 参考:clowder-ai 前端(借鉴"每猫单 hue 派生色板 + 正文中性"设计思想,色值与形态独立)

## 1. 目标

浏览器里完成平台全流程演示:建线程、@agent 对话、流式输出、审批卡片批准/打回、证据确认。视觉有辨识度("猫耳气泡"签名)。

## 2. 视觉系统

- 底色:暖米白 `#FAF7F1`;正文:暖深灰 `#2C2A27`;操作色:猫眼青绿 `#2F8F6B`;命令/mono 用系统等宽
- 每猫色板(hue 派生,气泡 surface + 徽章):
  - 墨墨(claude)墨蓝 `#E4EAF4` / 徽章底 `#3B5B8C`
  - 闪闪(gemini)紫 `#EDE7F6` / 徽章底 `#7C5CA8`
  - 团团(opencode)琥珀 `#F6EAD8` / 徽章底 `#B07A3C`
  - 用户:白纸气泡 + 细边框,徽章灰
- 签名:assistant 气泡左上"猫耳"(clip-path),配猫色相;用户气泡常规圆角
- 头像:圆形徽章,猫色底 + 白色单字(墨/闪/团/你)

## 3. 页面结构

```
顶部栏(品牌 + 在线状态)
├── 左:线程列表(新建按钮 + 条目:标题/时间)
└── 右:聊天区(消息流 + 审批卡片块 + 证据建议块 + 输入框)
```

## 4. 功能范围

1. 线程:列表、新建、切换
2. 消息:历史加载、WebSocket 流式追加(打字机,尊重 reduced-motion)、@mention/#命令高亮
3. 审批卡片:解析系统 📋 消息 → 卡片块(diff 统计 + 审查意见 + 批准/打回按钮,按钮发送命令)
4. 证据建议:解析 💡 消息 → 建议块 + 确认按钮
5. 配置:`NEXT_PUBLIC_API_URL`(默认 http://localhost:3200)

## 5. 非目标

登录/多用户、深色模式、设置页、移动端精调、消息编辑/删除、分页。

## 6. 技术栈

Next.js(App Router)+ React 19 + Tailwind v4(CSS-first)+ WebSocket 原生 API;测试:vitest + jsdom + Testing Library。

## 7. 测试策略

- 纯函数:`persona.ts`(agent→色板/名字)、`parse-message.ts`(系统消息→块类型)单测
- 组件:气泡渲染(猫耳/用户/系统)、卡片块按钮回调、建议块、输入框提交
- 验收:单测全绿;`pnpm dev`(根)起 Redis+API+Web,浏览器完整流程演示

## 8. 验收标准

1. `pnpm test` 全绿(新增用例 ≥ 12)
2. `pnpm dev` 一条命令起全套
3. 浏览器演示:建线程 → @墨墨 发消息(流式)→ 写手改动触发审批卡片 → 点批准 → 状态 applied;💡 建议 → 确认沉淀
