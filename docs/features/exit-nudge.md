- 靠拢:本刀只做「再唤同一只一次」。不替猫写 `@`，不做 `hold`，不 MCP 塞进同一轮。

## 门（各一句）

- **功能**：墨墨写完忘了 `@闪闪`，平台再问它一次，人不用先捡球。边界见 [AGENTS.md](../../AGENTS.md) 协议表
- **价值**：人少当事务员
- **愿景**：邮差提醒寄件人，不替猫选下一棒
- **落点**：`runSegment` 解析到 `no-handoff` 且该补出口时，再 `runTurn` 同一只一次

## 为什么

只给人看「球还在地上」，人还是路由器。他们对齐的是 exit check：先让猫补三选一。问答收尾、审查已写结论、`@人` 不补问。

## 怎么做

1. 无行首 `@`，且属于该交棒（收了棒 / 有 diff / 句中 @ / 审查官没结论）→ 系统句「出口未明」，再问同一只。
2. 补问 prompt 写明接 / 行首 `@` 下一只 / `@人`；审查官写「通过」或「需修改」即停。
3. 第二次仍没有出口 → 沿用现有「球还在地上」或句中提示。
4. 验收：有 diff 无 `@` 时同一只被叫两次，第二次行首 `@闪闪` 则交接；「你是谁」仍只叫一次。

## 不做（本篇）

- `hold_ball`、定时唤醒
- 平台按名册自动写 `@`
- 跨线程邮箱
