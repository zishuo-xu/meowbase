- 靠拢:本刀只改顶栏。不改打回轮数，不做 `hold`。

## 门（各一句）

- **功能**：闪闪写出「需修改」后，顶栏是「球在墨墨手上」，不是「球在人手里」
- **价值**：人不用猜该不该自己当中转
- **愿景**：邮差记球权，给人看
- **落点**：`describeBall`。认 `打回:`，或结论是 revise 时球回上一只写手

## 为什么

上一刀把通过和需修改都认成球回人。后端已经会打回写手，顶栏和邮差打架。

## 怎么做

1. 审查官已写「需修改」，且本轮不再流式 → 顶栏「球在写手手上」。
2. 已有 `打回:闪闪 → 墨墨` → 和接力一样，球在箭头右边。
3. 「通过」、待批卡片、已落地、升级、拉闸：行为不变。
4. 验收：接力后闪闪「结论:需修改」、还没有审批系统句 → 顶栏不是「球在人手里」。

## 不做（本篇）

- `hold_ball`
- 改打回轮数或路由
- 跨线程邮箱
