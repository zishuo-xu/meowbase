# 有 pending 时本轮不跑自动审查

上一刀交棒能等，有 diff 时审查仍绑在同一条上。本篇只拆开这一绑。

- 状态:`已落地`
- 对照 clowder:公开 A2A 是异步的。本篇只让审查也别抢在下一跳前面。

## 门（各一句）

- **功能**：墨墨交完，有改动也不立刻拉闪闪审
- **价值**：有文件时人也能离开
- **愿景**：仍是邮差；审查还在，只是延后
- **落点**：`settleTurn` 看见 pending 就跳过建卡。不新开队列

## 为什么

上一刀说闪闪稍后才跑，有 diff 时平台仍马上叫审查，人还是走不了。

## 怎么做

1. 本轮刚写下 pending → 不 `git diff`、不建卡、不跑审查。
2. 续跑结束且没有新 pending → 按现审批出卡。
3. 没交棒、只有 diff → 行为不变，当轮就审。
4. 验收：写文件并 `@闪闪` 后本轮无审批卡、闪闪 `runTurn` 为 0；「继续」之后才出卡。

## 不做（本篇）

- hold_ball、邮箱
- 审查排进看板、改状态机

## 入口

- `packages/api/src/router/execute-turn.ts` `settleTurn`
