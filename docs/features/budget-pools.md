# 按猫拆池与热改上限

## 门（各一句）

- **功能**：全平台上限仍拦;某只猫配了 `budgetUsd` 时,只拦点名它的那一跳。Hub 账本能改全平台上限和每只猫上限,保存立刻生效。
- **价值**：演示时能当场调闸,不必重启;面试能讲「贵的那只单独封顶」。
- **愿景**：仍是邮差。超重的包裹拒收,人拍板的系统命令仍能送。
- **落点**：`agentBudgets`;闸在路由之后按目标查该猫已花;`PATCH /api/config` 热改。

## 为什么

全平台闸已经有了,但改上限得改文件重启,也无法只封墨墨。对照他们:池子可拆、看板可改。喵窝差的就是热改和按猫。不做成 X:改了 Hub 还得重启才拦。

没配的猫不拦。gemini 不报成本,那只的池子永远花不满,不估。

## 怎么做

1. 配置加 `agentBudgets?: Partial<Record<AgentId, number>>`。Hub 账本两个输入:全平台、每只猫。空/≤0 当没配。
2. `PATCH /api/config { budgetUsd, agentBudgets }` 写进 live,落盘,下一跳就用新值。环境变量 `MEOW_BUDGET_USD` 仍覆盖全平台启动值,热改后以内存为准。
3. 闸:先全平台;过了再对每个目标看该猫 `costUsd` 合计。超了落 `budget`,文案带猫名,不调那只。
4. 验收:墨墨花满自己的上限、全平台还没满 → 点名墨墨拒、点名团团仍跑;Hub 改上限保存后下一跳按新值。

## 不做（本篇）

- 按日清零、按模型拆池
- 估算 gemini
- 实时推送用量

## 入口

- 闸:`packages/api/src/router/execute-turn.ts` 全平台之后按目标查 `agentBudgets`
- 配置:`budgetUsd` / `agentBudgets`;`PATCH /api/config` 热改 live 并落盘
- Hub 账本:全平台上限输入 + 每只猫上限
- 文案:`formatBudgetGateNote` 可带猫名
