# ＜这一刀的短名＞

一篇只写**一个**可验收的特性。写完就做这一刀，做完再开下一篇。不要在这里预写路线图。

- 状态:`设计中` → 落地后改 `已落地`
- 对照 clowder:同一问题他们公开怎么写（一句），不读源码

## 门（各一句）

- **功能**：人能多干什么
- **价值**：为什么值得做（不要写「更像他们」）
- **愿景**：仍是邮差？对不上就停
- **落点**：`executeTurn` / shared / 名册 / 系统消息 的哪一段。要新开邮箱、SOP、MCP、第二路由器则不做

## 为什么

不做成 X 会怎样。和他们对齐哪一条、本篇不拿哪一条。

## 怎么做

3–6 步。验收：发哪句、看见什么。不贴大段代码。

## 不做（本篇）

只列会和这一刀搅在一起的 2–3 条。其余以后另开篇。

## 入口

落地后填路径。
