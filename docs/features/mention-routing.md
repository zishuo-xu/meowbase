# 行首 @ 才点名

- 状态:`已落地`
- 对照 clowder:TIPS 写明另起一行、行首 `@` 才路由；句中不当目标。issue 里他们补过「句中 @ 未路由要给人看得到的提示」。我们对齐这条语义。
- 相关:[a2a.md](a2a.md)、协议表见 `AGENTS.md`

## 功能

人点名和猫交棒都只认行首 `@`。边界见 [AGENTS.md](../../AGENTS.md) 协议表。

## 价值

人能在句子里讨论名字而不误叫猫。猫交棒失败时人看得见（提示），提示本身不算球权。

## 愿景

点名是邮差的地址写法，不是 NLP。平台认格式，不猜「你是不是想叫闪闪」。

## 架构落点

`packages/shared/src/mention-targets.ts`（人）+ `packages/shared/src/a2a.ts` 的 `parseA2AHandoff`（猫）。`executeTurn` 只消费解析结果。

## 为什么这样设计

根因：句中 `@` 一旦也路由，人无法写「别叫闪闪」、猫无法在复盘里提到队友，球权会乱飞。clowder 公开踩过「软约束文本 @ 经常写错」。

| # | 决策 | 理由 |
|---|---|---|
| D1 | 人猫同一套：只认行首 | 规则只有一条，面试和演示都讲得清 |
| D2 | 同一行第二个 `@` 不算 | 防止 `@墨墨 @团团` 被当成并行；并行必须各占一行 |
| D3 | 中文名与英文 id 等价 | `@团团` = `@opencode`，名册 `aliases` |
| D4 | 句中 action-like `@` 出系统提示，提示不算球权 | 对齐他们「链条断裂要让人看见」；顶栏仍显示真正持球的人 |

## 怎么做

- 按行扫：行首可选空白后是 `@` + 名册里的名字/别名 → 收进目标列表。
- 剥 mention 得到任务正文：去掉行首点名行，留给猫的是题目。
- 无行首目标：最近一次行首点过的猫 → 最后开口 → 线程主猫。
- 猫回复同样只解析行首；解析空且句中像在叫人 → 插 `💡` 提示。

验收：发「不要 `@闪闪`\n@墨墨」只叫墨墨；同一行 `@墨墨 @团团` 只叫墨墨。

## 不做什么

- 不做意图识别 / 7B 分类来猜该叫谁（他们公开也写了 CJK 不准、成本高）
- 不把路由改成 MCP `targetCats`（那是他们后来的结构化通道，见 [async-a2a.md](async-a2a.md)）
- 群组展开见 [group-mentions.md](group-mentions.md)

## 面试能讲

- **30 秒**：地址写在行首，像邮件 To:。句中是正文。人和猫同一规则，所以「不要 @闪闪」不会叫它。
- **追问「为什么不智能一点」**：智能会把讨论变成误调用。格式是硬轨，模型是软的。
- **踩坑**：前端 IME 回车要认 composing，否则中文选词会误发送（和路由无关但常一起被问）。
- **若继续往 clowder 靠**：他们用结构化字段降低「猫不爱好好 at」。我们若加，只能当第二信号，行首规则先不动。
