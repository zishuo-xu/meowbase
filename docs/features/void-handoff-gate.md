# 虚空传球门禁

- 状态:`已落地`
- 对照 clowder:[F167](https://github.com/zts212653/clowder-ai/blob/main/docs/features/F167-a2a-chain-quality.md) 把「语义上交了棒、但没有任何系统动作」叫虚空传球,和乒乓熔断一起当运行时刹车。
- 靠拢:靠「运行时数一眼再决定要不要把球传下去」这条。**本刀只做虚空那一半**,乒乓那半在喵窝结构上已经不成立(`visited` + 链深 3;记分板「想交回已出场的猫」三次全判 `blocked`)。不靠他们的 `hold_ball` MCP 工具,也不做角色护栏。

## 门（各一句）

- **功能**:猫这一跳什么都没留下就想把球丢给下一只时,平台不传,球回到人手里并说清原因。
- **价值**:人不用等一轮空转才发现没人干活;也省掉下一只猫对着空气审查的那次模型调用。
- **愿景**:仍是邮差。平台不判断内容好不好,只看这一跳**有没有留下东西**——空信封不投递。
- **落点**:`shared/src/a2a.ts` 一个纯函数 + `turn/segment.ts` 接受交棒前一个判断(`relayFiles` 已经在那一行算好了)。不新开心脏,不动前端。

## 为什么

记分板上这一格现在是 0:`pnpm eval` 的「什么都没干就交棒」跑三次,三次都没人拦。fake 写手回一句「先交给闪闪看一眼」+ 行首 `@闪闪 请审查`,不改文件、不写结论,平台照传。下一只猫收到一个空交接包,只能回「没东西可审」,于是烧掉一次模型调用,球还落在一个说不清的位置。

出口补问治的是**漏传**(该交棒却没给出口),这一刀治的是**空传**(给了出口但手里是空的)。F167 把这两件事放在同一篇里,是因为它们是一枚硬币的两面。

## 怎么做

判断只在「即将接受交棒」那一步做,而且**必须 fail-open**:三个信号全部缺失才拦,任何一个在就照传。

1. 新纯函数 `isVoidHandoff({ changedFiles, reply })`,三条全中才为真:
   - 这一跳没有新文件(`relayFiles.length === 0`,现成的)
   - 回复里没有结论段(`hasExplicitReviewVerdict === false`,现成的)
   - 回复去掉行首 `@` 那几行和空白后,剩下的正文短于阈值(按字符数,CJK 按字算)
2. `turn/segment.ts` 在写 `pendingHop` 之前调它。真:不写 pending、不发 `relay` 系统句,`stop = { kind: 'void', blockedTarget: 目标 }`。
3. `A2AStopKind` 加 `'void'`;`formatDroppedBallNote` 给它一句专门的话,写清谁想把什么交给谁、为什么没传。系统消息仍用 `systemKind: 'dropped'`——球权语义没变,前端一行不改。
4. 审计不用手写:系统消息一 append 就在 store 边界落存根。

**阈值不是精确科学**,方向是宁可漏拦不可错拦:fake 那句剩 9 个字,一份真方案是几百字,中间留很宽的余量。选定后写进测试,别在实现里悄悄调。

验收:

- `pnpm eval` 的「什么都没干就交棒」从 0 变 1。**这会让 eval 因为「期望 0 实际 1」先变红**,然后同一轮把那行期望改成 1——这正是记分板设计时要的那个闭环,不是意外。
- `pnpm e2e` 三段仍绿(happy 的写手改了文件才交棒,有 diff,不该被拦)。
- 新单测锁住**最重要的一条**:正文长、没文件、没结论的交棒(「方案在上面,@团团 去实现」)**不许被拦**。这条比拦住 fake 那条更重要。

### 已知误拦(不藏)

人明说「@墨墨 转给闪闪」时,墨墨确实什么都没留下,会被拦。代价是一句系统话,人照着捡球句再发一次即可;换来的是不必为这种情形在门禁上开一个「人授权过」的口子。哪天真烦到人,再另开一篇。

落地时量到一件该记下的事:**原有十来处 api 测试的桩回复被这一刀拦住了**,像「写完了。\n@opencode 请审查」这种短句加交棒(桩不真写文件,所以没有 diff)。那些用例测的是接力机制本身,所以给它们垫了一段长正文,不是放宽断言。但它说明短句交棒是个**常见形状**,这一刀比「只拦明显的垃圾」更激进。

两个方向的代价都很小,所以 60 这个数不是安全底线,是可调的旋钮:错拦一次的代价是一句系统话加人重发一遍,漏拦一次的代价是浪费一次模型调用。真实模型的回复通常是几百字,fake 那句是 9 个字,中间余量很宽。

## 不做（本篇）

- 乒乓熔断(同一对猫跨轮空转计数):喵窝链内已经拦住,跨轮要新账本,另开篇。
- 角色护栏(设计师别写代码):要按角色配规则,和这一刀的「有没有留下东西」是两码事。
- 判断内容质量:平台只看有没有,不看好不好。要看好不好是验证闸和审查官的活。
