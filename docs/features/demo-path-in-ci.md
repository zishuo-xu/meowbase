# 演示路径进 CI:人打字那一层也要有人管

- 状态:`已落地`
- 对照 clowder:**他们没有产品级浏览器 E2E 进 CI。** 公开 `ci.yml` 的闸是 Lint、Build、Test (Public)、Directory Size Guard（另有 Windows smoke），没有 web 测、没有 Playwright job，仓里也没有 `playwright.config` / `tests/e2e`。他们的 UI 验收公开写成「**真启动 dev / alpha 走一遍**」（LL-032:狼人杀 92 个单测全绿但 dev 里关不掉、不会动，修复是启动 dev 做真实 E2E），并且明确说单测那层的 `fake spawnFn` / mock 全绿**不算验收**（LL-064、LL-063）。
- 靠拢:**这一刀靠的是他们的原则，不是他们的做法**——单测绿不等于界面能用;验收环境必须和活着的 runtime 隔开端口和 Redis（LL-015 忘设 Redis 打到生产库丢 95% key、LL-035、LL-049）;闸失效要 fail-close 不许装绿（#1321 排除项过期就让整条公开闸变红）。**本刀故意比他们走得更远一步**:把「真起一回、走通核心流程」从「人记得做」变成「机器每次都做」。理由是我们没有 alpha 通道、没有 operator Bootcamp、也没有第二个人复核，而人手走查**已经漏过一次**（见下）。所以这里不是「没能靠更近」，是**明知他们没做而选择多做一步**。
  - 有一件事**不能**说成靠拢:公开材料里**没有**「测试不许花钱」这条原则，也**没有** fake CLI 二进制这种做法（他们是 mock `spawnFn` + 把部分 agent runtime 测排除出 `test:public`）。喵窝的 fake CLI 是自己的东西，别写成学他们的。

## 门（各一句）

- **功能**:CI 每次自动打开真界面、真打字、真点，走完演示主路径。
- **价值**:人不必记得走查;漏走查也不会假装通过。
- **愿景**:仍是邮差——这一刀不加任何产品能力，只是把已有能力钉住。
- **落点**:新 `scripts/e2e-web.ts`，复用 `scripts/lib/harness.ts` 的起服务接线。不碰 `executeTurn`。

## 为什么

`pnpm e2e` 已经在 API 层验了全链、崩溃续跑、绑端口冲突。**浏览器这一刀独有的不是再验一遍链路，是「人打字那一层」和「渲染那一层」——它们现在零覆盖。**

而且这不是假想的风险，已经真的漏过:人手走演示时漏打了那行 `@墨墨`，流程照样跑通（不写 `@` 会兜到线程主猫，而演示里点的恰好也是主猫），于是**看起来全绿，其实多行输入和行首 `@` 路由两条都没测到**。这正是 LL-032 那个形状:绿的东西和你以为它证明的东西不是一回事。

所以本刀最要紧的一句是:**断言必须打到不是主猫的那只**。否则兜底会替我们把测试变成空的——这条一旦写松，整刀就白做。

## 怎么做

1. Playwright（只 chromium）+ 新 gate `pnpm e2e:web`。**五道闸变六道**，`AGENTS.md` / `ARCHITECTURE.md` / `PROGRESS.md` / `push-boundary.md` 里那 8 处「五道闸」同一轮改掉。
2. **不塞进 `pnpm e2e`**:那样每次跑 e2e 都得装 chromium。**也不允许「装不上就跳过」**——那是踩坑第 20 条那种假绿，装不上就该红（对齐他们 #1321 的 fail-close）。
3. 起服务:复用 `harness.ts` 的 `startApi`（fake CLI，不花钱），**Redis 用第 12 号库**（14 归 e2e、13 归 eval，共用会抢棒:踩坑 17、22）。公共接线只许一份，不准再抄一遍（踩坑 23）。
4. **API 端口对这个测试是固定的**，因为 `NEXT_PUBLIC_API_URL` 是 **build 时内联**的，没法像 e2e 那样随机挑端口再告诉前端。所以这个测试**单独 build 一次 web**，把测试端口烤进去。代价是 CI 多一次构建;换来的是本地跑不会撞你正开着的 3200。另一条路（复用现成构建、把 API 绑到 3200）被否掉:那是典型的「CI 里绿、本地跑就炸」。端口仍要避开 3200/3300（`FORBIDDEN_PORTS`）。
5. 断言只盖**输入层和渲染层**这四条，每条都要能独立失败:
   - **多行输入**:`Shift+Enter` 换行，`@团团` 自己占一行发出去;用户气泡里它**仍然自己占一行**（不是挤成一段，也不是第一行被单独发走）。
   - **行首 `@` 真的路由**:线程主猫是墨墨，点名 **团团**，断言开口的是团团。路由坏掉退回主猫时这条必须红。
   - **补全菜单里 Enter 是选候选不是发送**:打 `@` 弹出菜单后按 Enter，断言消息**没有**被发出去。
   - **看得见的收尾**:接力系统句、顶栏球权文案、审批卡出现;点批准后顶栏变「已落地」。
6. 本地跑必须在**沙箱外**（踩坑第 2 条:Next 在沙箱里枚举网卡会 EPERM 起不来）。这一条写进 `README` 跑测试那段。

## 不做（本篇）

- **不盖崩溃恢复、持球、升级、绑仓、Hub、账本、拉闸**。它们在 `pnpm e2e` / `pnpm eval` / 单测里已经有覆盖，本刀只补零覆盖的那两层。以后要加就另开篇。
- **不改前端取 API 地址的方式**。改成同源代理（`/api/*` 由 Next 转给后端）能顺带消掉 build 时内联和一部分 CORS/Origin 复杂度，但那是产品改动，单独一篇。
- **不追求把 `DEMO.md` 每个可选分支都自动化**。那份文档是给人念的，本刀只钉主路径。

## 入口

- 闸：`pnpm e2e:web`（`scripts/e2e-web.ts` 起服务，`scripts/e2e-web.spec.ts` 四条断言）
- 接线：复用 `scripts/lib/harness.ts` 的 `startApi`；Redis db 12；web 独立 `packages/web/.next-e2e`
- CI：`.github/workflows/ci.yml` 装 chromium 后跑 `pnpm e2e:web`
